# MediaPipe Universal Embedder task for web

## Overview

Our web sample runs universal embedding on multi-modal inputs, projecting text,
images, and audio into a single shared vector space. It then determines how
alike the inputs are using cosine similarity.

## Prerequisites

* A device that can access the web using Chrome, Firefox, or Safari
* For iOS devices, iOS 16 or later

## Running the demo

Web demos are hosted in a the
[MediaPipe Sample Web](https://github.com/google-ai-edge/mediapipe-samples-web/)
repository.

# MediaPipe Semantic Retriever task for web

## Overview

Our web sample demonstrates on-device semantic retrieval. It embeds data into
vectors and stores them in a vector store, allowing you to retrieve the closest
matches by semantic meaning using cosine similarity.

## Prerequisites

* A device that can access the web using Chrome, Firefox, or Safari
* For iOS devices, iOS 16 or later

## Running the demo

Web demos are hosted in a the
[MediaPipe Sample Web](https://github.com/google-ai-edge/mediapipe-samples-web/)
repository.
